# Thymeleaf docs proposal

An independent demo of how the [Thymeleaf](https://www.thymeleaf.org) website and documentation could look, built by a Thymeleaf user for the maintainers to evaluate.

**This isn't an official Thymeleaf project.** The official site and docs are at [thymeleaf.org](https://www.thymeleaf.org).

Live demo: <https://wimdeblauwe.github.io/thymeleaf-new-docs/>

## Development

This project uses [Astro](https://astro.build) with [Starlight](https://starlight.astro.build) and needs pnpm.

| Command        | Action                                     |
| :------------- | :----------------------------------------- |
| `pnpm install` | Install dependencies                       |
| `pnpm dev`     | Start the dev server at `localhost:4321`   |
| `pnpm build`   | Build the site to `./dist/`                |
| `pnpm preview` | Preview the build locally                  |

Pushes to `main` deploy to GitHub Pages.
